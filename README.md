# 火力冲刺

一个面向手机浏览器的竖屏 3D 自动射击跑酷游戏：玩家左右拖动选择路线，在徒步与载具关卡中自动攻击障碍和敌人，最终挑战 Boss。开始界面可直接选择五个完整关卡，通关后也可连续进入下一关。

当前包含五个独立战区：地表与矿洞交替的「荒原矿脉」、从地面跑道爬升至云层的「云端追猎」、全程驾驶潜艇的「深海潜航」、徒步闯入熔岩神殿的「地狱终局」，以及全程乘坐矿车穿越废弃矿井、晶矿深坑和地心宝库的「幽晶矿车」。所有路线都具有独立的转弯、上坡、下坡或俯冲变化。每关长度与内容量已扩展约 50%，现包含三个长段落、15 个普通敌人、1 个 Boss、9 个必须射爆的主题障碍、8 个道具和 9–10 组正负强化门。所有徒步与载具战斗都只朝前方攻击，后向射击和回头镜头机制已移除。

成长路线包含最多 6 人的可见战斗编队、射击增伤、多弹道、步枪和加特林升级。每名队员都会参与射击并显示当前枪模；战车、矿车、战机和潜艇也会随升级切换可见的单炮、双联炮与旋转加特林。红色负面门会降低伤害、射速或队伍人数。全屏炸弹会造成范围伤害，并显示扩张冲击波、爆破粒子、命中/摧毁统计和独立低频爆炸音效；关卡中另有护盾、磁铁和医疗包，以及必须在撞上前射爆的普通/致命障碍。

敌人分为普通怪、重甲坦克、冲刺怪、飞行怪和 Boss。所有敌人和可破坏障碍都会显示始终朝向镜头的实时血条。武器、跑步、怪物、增益门与 Boss 阶段使用项目专属生成音效，并通过 Web Audio 做随机变体、队伍齐射声像和动态压缩；Kenney CC0 素材作为界面与加载失败兜底。详细来源见 `AUDIO-CREDITS.md`。

步枪、加特林、战车、战机和 Boss 使用异步加载的 PBR GLB 资产，矿车使用带车斗、矿灯和滚动车轮的专用低多边形模型；程序化模型也作为首屏和加载失败兜底。运行时模型已减面并将纹理压缩到适合移动端的尺寸，详见 `MODEL-ASSETS.md`。

## 本地运行

```bash
npm install
npm run dev
```

终端会显示本地访问地址。手机与电脑处于同一局域网时，也可以使用终端显示的 Network 地址在手机浏览器中打开。

## 操作

- 手机：在游戏画面中按住并左右拖动
- 电脑：左右方向键或 `A` / `D`
- 攻击会自动进行

## 验证

```bash
npm test
npm run build
```

## 技术结构

- `src/game/simulation.ts`：与渲染分离的玩法规则、前后向自动攻击、障碍、道具、碰撞和成长
- `src/game/level.ts`：怪物、障碍、道具、强化门及多主题章节配置
- `src/game/world.ts`：Three.js 场景、异步 GLB、程序化兜底模型、主题地图、载具、特效与相机
- `src/game/input.ts`：触屏拖动和键盘操作映射
- `src/game/audio.ts`：分武器/事件的 Web Audio 混音、循环、压缩与合成兜底
- `src/main.ts`：游戏循环与 DOM HUD 协调
